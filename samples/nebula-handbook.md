# 네뷸라랩스(Nebula Labs) 개발팀 핸드북

> 이 문서는 RAG 테스트용 가상 문서입니다. 등장하는 회사, 제품, 규칙은 모두 허구입니다.

## 1. 회사 소개

네뷸라랩스는 2019년 제주도에서 설립된 스타트업으로, 반려식물 관리 앱 **"플랜티(Planty)"**를 서비스하고 있습니다.
창업자는 윤서하 대표이며, 현재 직원 수는 47명입니다. 본사는 제주시 첨단로 88에 있고, 서울 성수동에 분사무실이 있습니다.

회사의 핵심 가치는 다음 세 가지입니다.

1. **초록 우선(Green First)**: 모든 의사결정에서 환경 영향을 먼저 고려합니다.
2. **작게 자주 배포**: 큰 기능도 작은 단위로 나누어 하루에 여러 번 배포합니다.
3. **문서로 말하기**: 중요한 결정은 반드시 설계 문서(RFC)로 남깁니다.

## 2. 플랜티 서비스 개요

플랜티는 사용자가 키우는 식물의 사진을 찍으면 AI가 식물 종류와 건강 상태를 진단해 주는 앱입니다.
2025년 12월 기준 월간 활성 사용자(MAU)는 32만 명이며, 가장 많이 등록된 식물은 몬스테라, 두 번째는 스투키입니다.

주요 기능:

- **잎 진단**: 잎 사진으로 병충해와 영양 결핍을 진단합니다. 진단 정확도는 91.4%입니다.
- **물주기 알림**: 식물 종류, 화분 크기, 지역 습도를 고려해 물 주는 날을 알려줍니다.
- **식물 일기**: 성장 과정을 사진과 함께 기록합니다.
- **플랜티 마켓**: 2026년 3월에 출시된 기능으로, 사용자 간 식물 분양을 중개합니다. 거래 수수료는 5%입니다.

## 3. 기술 스택

| 영역 | 기술 |
|---|---|
| 모바일 앱 | Flutter 3 |
| 웹 관리자 | Next.js, TypeScript |
| API 서버 | Go (Gin 프레임워크) |
| AI 진단 서버 | Python, FastAPI, PyTorch |
| 데이터베이스 | PostgreSQL 16, Redis |
| 인프라 | AWS 서울 리전, Kubernetes(EKS) |
| 모니터링 | Grafana, Sentry |

AI 진단 모델의 이름은 **"리프넷(LeafNet) v4"**이며, 약 180만 장의 식물 이미지로 학습했습니다.
모델 추론은 GPU 서버가 아닌 **AWS Inferentia** 인스턴스에서 실행해 비용을 약 40% 절감했습니다.

## 4. 개발 프로세스

### 4.1 브랜치 전략

- 기본 브랜치는 `main`이며, 모든 작업은 `feature/<티켓번호>-<간단한설명>` 형식의 브랜치에서 진행합니다.
  - 예시: `feature/PLT-1234-watering-alert`
- 긴급 수정은 `hotfix/` 접두사를 사용합니다.
- `main`에 직접 푸시하는 것은 금지되어 있습니다.

### 4.2 코드 리뷰 규칙

- 모든 PR은 **최소 2명의 승인**이 필요합니다. 단, 문서만 수정한 PR은 1명의 승인으로 충분합니다.
- PR은 변경 줄 수가 **400줄을 넘지 않도록** 권장합니다.
- 리뷰 요청 후 **영업일 기준 24시간 이내**에 첫 리뷰를 남기는 것이 원칙입니다.
- 리뷰 코멘트에는 접두사를 붙입니다.
  - `[필수]`: 반드시 수정해야 머지 가능
  - `[제안]`: 수정하면 좋지만 선택 사항
  - `[질문]`: 이해를 돕기 위한 질문

### 4.3 배포

- 배포는 매일 **오전 10시, 오후 3시** 두 번 정기적으로 진행합니다.
- **금요일 오후 3시 이후에는 배포를 금지**합니다. 이를 사내에서는 "금요일 평화 규칙"이라고 부릅니다.
- 핫픽스는 시간 제한 없이 배포할 수 있지만, CTO 또는 당직자의 승인이 필요합니다.
- 배포는 카나리 방식으로 진행하며, 트래픽의 5% → 25% → 100% 순서로 확대합니다. 각 단계는 최소 15분간 유지합니다.

## 5. 장애 대응

### 5.1 장애 등급

| 등급 | 기준 | 최초 대응 시간 |
|---|---|---|
| SEV1 | 전체 서비스 중단 또는 데이터 유실 | 15분 이내 |
| SEV2 | 핵심 기능(진단, 로그인) 장애 | 30분 이내 |
| SEV3 | 일부 기능 오류, 우회 가능 | 영업일 1일 이내 |

### 5.2 당직(On-call)

- 당직은 백엔드 개발자 8명이 **1주일 단위로 순환**합니다.
- 당직 수당은 주당 20만 원이며, 야간(오후 10시~오전 7시)에 실제 호출되면 건당 5만 원이 추가됩니다.
- 장애가 해결되면 **3영업일 이내**에 포스트모템 문서를 작성해야 합니다. 포스트모템은 누구의 잘못인지 따지지 않는 "비난 없는(blameless)" 형식으로 작성합니다.

## 6. 근무 제도와 복지

- 근무 시간: 코어타임은 **오전 11시 ~ 오후 4시**이며, 나머지 시간은 자율입니다.
- 원격 근무: 주 3일까지 가능합니다. 단, 매주 화요일은 전 직원이 출근하는 "모이는 날"입니다.
- 휴가: 입사 첫해부터 연차 20일이 주어집니다.
- 교육비: 연간 200만 원까지 도서, 강의, 컨퍼런스 비용을 지원합니다.
- 반려식물 수당: 사무실 책상에서 식물을 키우는 직원에게 월 1만 원의 "초록 수당"을 지급합니다.
- 장비: 입사 시 노트북(맥북 프로 또는 씽크패드 중 선택)과 모니터 2대를 지급합니다.

## 7. 신규 입사자 온보딩

첫 주 일정은 다음과 같습니다.

1. **1일차**: 장비 수령, 계정 발급, 윤서하 대표와의 점심 식사
2. **2일차**: 로컬 개발 환경 구축, 사내 위키 읽기
3. **3일차**: 버디(온보딩 멘토)와 함께 "첫 PR" 만들기 — 보통 오타 수정이나 README 개선
4. **4일차**: 장애 대응 훈련(모의 SEV2 상황)
5. **5일차**: 한 주 회고 및 제주 본사 식물원 투어

신규 입사자는 입사 후 **4주 동안 당직에서 제외**되며, 5주차부터 당직 순환에 참여합니다.

## 8. 자주 묻는 질문 (FAQ)

**Q. 사내 메신저는 무엇을 쓰나요?**
A. 슬랙(Slack)을 사용합니다. 장애 알림은 `#incident` 채널, 배포 알림은 `#deploy` 채널로 전송됩니다.

**Q. 개발 서버 접속 방법은?**
A. 사내 VPN(WireGuard)에 연결한 뒤 `dev.nebula.internal`로 접속합니다. VPN 설정 파일은 IT팀 김도윤 매니저에게 요청하세요.

**Q. 점심 식사는 어떻게 하나요?**
A. 제주 본사는 사내 카페테리아에서 무료로 제공되며, 성수 사무실은 1인당 하루 1만 2천 원의 식대가 지원됩니다.
