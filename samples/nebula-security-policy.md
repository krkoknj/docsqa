# 네뷸라랩스 정보보안 정책

> RAG 테스트용 가상 문서입니다. 등장하는 회사, 제품, 규칙은 모두 허구입니다.

## 1. 목적과 적용 범위

이 정책은 네뷸라랩스 임직원, 인턴, 외부 협력사 직원 모두에게 적용됩니다.
정책 책임자는 CISO(정보보호최고책임자) 한지우이며, 정책은 매년 1월에 개정됩니다.
정책 위반 시 인사위원회에 회부될 수 있습니다.

## 2. 계정과 비밀번호

- 비밀번호는 **최소 14자** 이상이며, 대문자·소문자·숫자·특수문자 중 3종류 이상을 포함해야 합니다.
- 비밀번호는 **180일마다** 변경해야 하며, 최근 5개 비밀번호는 재사용할 수 없습니다.
- 로그인 5회 연속 실패 시 계정이 **30분간 잠깁니다**.
- 모든 사내 시스템은 **MFA(다중 인증)**가 필수입니다. 허용되는 MFA 수단은 하드웨어 보안 키(YubiKey)와 OTP 앱이며, SMS 인증은 2025년 7월부터 금지되었습니다.
- 퇴사자의 계정은 퇴사일 **당일 오후 6시**에 자동으로 비활성화됩니다.

## 3. 접근 권한 등급

| 등급 | 대상 | 접근 가능 범위 |
|---|---|---|
| L1 | 전 직원 | 사내 위키, 메신저, 공용 드라이브 |
| L2 | 개발자 | 개발·스테이징 환경, 소스 저장소 |
| L3 | 시니어 개발자, SRE | 운영 환경 읽기 권한, 로그 조회 |
| L4 | CTO, 보안팀 | 운영 DB 쓰기 권한, 고객 개인정보 원본 |

- L3 이상 권한은 **분기마다** 재승인을 받아야 합니다.
- 운영 DB 쓰기 작업은 반드시 2인이 함께 수행하는 "투맨 룰"을 따릅니다.
- 권한 신청은 사내 포털의 `ACCESS-REQ` 양식으로 합니다.

## 4. 보안 사고 등급

보안 사고는 서비스 장애와 별도로 분류합니다.

| 등급 | 예시 | 보고 기한 |
|---|---|---|
| P1 | 고객 개인정보 유출, 랜섬웨어 감염 | 인지 후 **1시간 이내** CISO 보고 |
| P2 | 내부 계정 탈취, 악성코드 감염 PC | 인지 후 4시간 이내 보고 |
| P3 | 피싱 메일 수신, 정책 위반 의심 | 영업일 1일 이내 보고 |

P1 사고로 개인정보가 유출된 경우, 관련 법령에 따라 **72시간 이내**에 개인정보보호위원회에 신고합니다.

## 5. 기기와 원격 접속

- 회사 노트북은 디스크 전체 암호화(FileVault 또는 BitLocker)가 필수입니다.
- 화면 잠금은 **5분** 동안 입력이 없으면 자동으로 걸려야 합니다.
- 노트북을 분실하면 **2시간 이내**에 보안팀(`#security-help` 채널)에 알려야 하며, 보안팀은 원격으로 기기를 초기화합니다.
- 카페 등 공용 와이파이에서는 반드시 사내 VPN(WireGuard)을 켜야 합니다.
- 개인 기기(BYOD)로는 메신저와 메일만 사용할 수 있고, 소스 코드는 내려받을 수 없습니다.

## 6. 데이터 분류와 보존

| 분류 | 예시 | 보존 기간 |
|---|---|---|
| 공개 | 블로그 글, 채용 공고 | 제한 없음 |
| 내부 | 회의록, 설계 문서 | 5년 |
| 기밀 | 계약서, 재무 자료 | 10년 |
| 개인정보 | 고객 이메일, 결제 정보 | 회원 탈퇴 후 **30일** 뒤 파기 |

식물 사진은 개인정보로 분류하지 않지만, 사진에 포함된 위치 정보(EXIF GPS)는 업로드 시 자동으로 제거합니다.

## 7. 취약점 신고 보상 프로그램

외부 보안 연구자가 플랜티의 취약점을 신고하면 심각도에 따라 보상금을 지급합니다.

- Critical: 최대 **500만 원**
- High: 최대 200만 원
- Medium: 최대 50만 원
- Low: 기념품(플랜티 화분 키트)

신고는 security@nebula.example 로 받으며, 접수 후 **3영업일 이내**에 1차 답변을 드립니다.

## 8. 보안 교육

- 신규 입사자는 입사 **2주 이내**에 보안 기초 교육을 이수해야 합니다.
- 전 직원은 매년 11월 정기 보안 교육을 받습니다.
- 분기마다 모의 피싱 훈련을 진행하며, 2회 연속 링크를 클릭한 직원은 추가 교육을 받습니다.
