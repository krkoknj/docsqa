# 플랜티 파트너 API 가이드 v2

> RAG 테스트용 가상 문서입니다. 등장하는 회사, 제품, 규칙은 모두 허구입니다.

플랜티 파트너 API는 화원, 원예 쇼핑몰 같은 제휴사가 플랜티의 식물 진단 기능을 자사 서비스에 붙일 수 있도록 제공하는 REST API입니다.

## 1. 기본 정보

- 베이스 URL: `https://api.planty.example/v2`
- 모든 요청과 응답은 JSON(UTF-8)입니다.
- 시간은 모두 ISO 8601 형식의 UTC로 표기합니다.
- 샌드박스 환경은 `https://sandbox.planty.example/v2`이며, 샌드박스의 진단 결과는 항상 고정된 예시 값을 반환합니다.

## 2. 인증

- 모든 요청에는 `X-Planty-Key` 헤더에 API 키를 넣어야 합니다.
- API 키는 파트너 콘솔에서 발급하며, 키 하나당 최대 **3개의 IP 주소**만 허용 목록에 등록할 수 있습니다.
- API 키는 **1년** 뒤 만료되며, 만료 30일 전에 담당자 이메일로 안내가 발송됩니다.
- 키가 유출되었다면 콘솔에서 즉시 "키 회전(rotate)"을 실행하세요. 이전 키는 **24시간** 동안 함께 동작한 뒤 폐기됩니다.

## 3. 요청 한도 (Rate Limit)

| 요금제 | 분당 요청 수 | 월간 진단 횟수 |
|---|---|---|
| Seed | 60 | 1,000회 |
| Sprout | 300 | 20,000회 |
| Tree | 1,200 | 무제한 |

- 한도를 넘으면 `429 Too Many Requests`와 함께 `Retry-After` 헤더(초 단위)를 반환합니다.
- 월간 진단 횟수는 매월 1일 0시(UTC)에 초기화됩니다.

## 4. 주요 엔드포인트

### 4.1 잎 진단 요청

`POST /diagnoses`

- 요청 본문에 `image_url` 또는 base64 인코딩된 `image` 중 하나를 넣습니다.
- 이미지는 최대 **8MB**, JPEG 또는 PNG만 지원합니다.
- 진단은 비동기로 처리되며, 응답으로 `diagnosis_id`와 상태 `pending`을 받습니다.
- 평균 처리 시간은 약 **3초**입니다.

### 4.2 진단 결과 조회

`GET /diagnoses/{diagnosis_id}`

- 상태는 `pending`, `completed`, `failed` 중 하나입니다.
- `completed`일 때 `species`(식물 종), `health_score`(0~100), `issues`(병충해·영양 결핍 목록)가 포함됩니다.
- `health_score`가 **40 미만**이면 `issues`에 반드시 1개 이상의 항목이 있습니다.

### 4.3 물주기 일정 계산

`GET /watering-schedule?species=monstera&pot_size=M&region=jeju`

- `pot_size`는 `S`, `M`, `L` 중 하나입니다.
- `region`에는 시·도 단위 지역 코드를 넣습니다. 지역 습도 데이터는 매일 새벽 4시에 갱신됩니다.

## 5. 웹훅

- 진단이 끝나면 파트너가 등록한 URL로 `diagnosis.completed` 이벤트를 보냅니다.
- 웹훅 요청에는 `X-Planty-Signature` 헤더가 포함되며, 파트너 시크릿으로 HMAC-SHA256 서명을 검증해야 합니다.
- 파트너 서버가 2xx로 응답하지 않으면 **최대 5번**, 1분·5분·30분·2시간·12시간 간격으로 재전송합니다.

## 6. 에러 코드

| 코드 | HTTP 상태 | 의미 |
|---|---|---|
| `PLT-E401` | 401 | API 키가 없거나 잘못됨 |
| `PLT-E403` | 403 | 허용되지 않은 IP에서 요청 |
| `PLT-E413` | 413 | 이미지가 8MB를 초과함 |
| `PLT-E422` | 422 | 이미지에서 식물을 찾지 못함 |
| `PLT-E429` | 429 | 요청 한도 초과 |
| `PLT-E503` | 503 | 진단 서버 점검 중 |

`PLT-E422`가 반복되면 식물이 화면의 절반 이상을 차지하도록 다시 촬영하도록 사용자에게 안내하세요.

## 7. 버전 정책

- v1 API는 **2026년 6월 30일**에 종료되었습니다.
- 새 메이저 버전이 나오면 이전 버전은 최소 **12개월** 동안 유지됩니다.
- 하위 호환이 깨지는 변경은 파트너 콘솔 공지와 이메일로 90일 전에 알립니다.
